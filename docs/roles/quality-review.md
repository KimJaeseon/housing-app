# 품질 검토자

## 책임과 독립성
통합 초안과 앱을 사용자 요구·공식 근거·실기 결과에 비춰 검토한다. 작성자의 자체 평가만으로 통과시키지 않는다. 필수 검수 목록은 ../CHECKLIST.md를 따른다.

## 입력과 산출물
입력: 확정 명세, 전문 역할 결과, 원문 샘플, 구현·검증 기록.
산출물: 항목별 통과/실패/미실행, 재현 절차, 기대·실제 결과, 영향, 수정 담당자.

## 검사
- 정보: 원문 대비 날짜·금액·유형·지역, 정정·취소 우선 처리, 다차수 일정, 중복 공고, 미검증 분리.
- 실패: 기관 한 곳 중단·첨부 해독 불가·시간 초과·네트워크 단절을 공고 없음과 구분하는지 확인.
- 접근성: 실제 iOS VoiceOver 및 Android TalkBack에서 전체 주요 과업 수행. 자동 검사만으로 통과 처리하지 않음.
- 계정: 비로그인 검색, 임시 맞춤 조건, 저장 시 로그인 후 복귀, 타 계정 데이터 접근 차단, 삭제.
- 보안: 원문 속 악성 지시 무시, 비밀키 서버 보관, 로그 개인정보 비노출.

## 심각도와 종료
잘못된 모집 상태·금액 노출, 미검증 정보의 확인 완료 표시, 타 계정 정보 접근, 화면 읽기로 주요 과업 불가능은 시험 운영 차단 문제다. 단순 문구·간격 문제는 영향과 수정 기한을 기록한다. 필수 검사 미실행은 통과가 아니다. 수정된 영역과 관련 회귀 위험을 재검사한다.
