# 수도권 공공주택 청약 조사 앱 — 프로젝트 명세

## 목적과 출시 범위
사용자가 수도권 도시·지역을 입력하면 공공주택 청약 공고를 공식 출처에서 조사하고 검증하여 제공하는 Android·iOS 모바일 앱을 만든다. 첫 산출물은 실제 조사·로그인·저장 기능이 연결된 제한된 사용자 대상 시험 운영 앱이다. 앱스토어 공개 배포는 이번 완료 기준에 포함하지 않는다. 프로젝트명은 설명용 임시 명칭이다.

## 확정 요구사항
- 지역: 서울·경기·인천. 서울·인천은 광역시 단위, 경기도는 시·군 단위로 검색할 수 있게 설계한다. 동명 지역은 사용자에게 구분을 요청한다.
- 유형: 장기전세, 국민임대, 행복주택, 공공임대, 매입임대, 전세임대 등 공공 임대주택과 공공분양. 민간 아파트 분양은 제외한다. 단순히 민간 사업자가 참여했다는 이유로 공공주택을 제외하지 말고 공식 모집 유형을 확인한다.
- 상태: 접수 중·접수 예정 공고만 기본 대상이다. 일반 공급계획·마감·취소 공고는 활성 청약 목록에 포함하지 않는다.
- 기본 기능: 도시별 조회. 선택 기능: 나이·가구·무주택·소득·자산 등 조건을 통한 참고용 맞춤 검색. 확정적인 당첨·자격 보장은 하지 않는다.
- 수집: 사용자가 검색할 때마다 공식 출처를 새로 조사한다. 조사 중 상태와 검증 완료 결과를 순차 제공한다.
- 표시: 확인된 공고만 기본 목록에 표시한다. 검증 부족·충돌 공고는 이유와 함께 ‘확인 필요’에 분리한다.
- 화면: 목록과 상세, 주소·지역명으로 위치 제공. 지도 기능은 만들지 않는다.
- 계정: 기본 검색과 임시 맞춤 검색은 로그인 없이 이용한다. 관심 공고·맞춤 조건 저장은 로그인 후 제공한다.
- 접근성: VoiceOver·TalkBack만으로 모든 주요 과업을 완료할 수 있어야 한다.

## 기술 기본안
React Native + Expo + TypeScript 모바일 앱, Python + FastAPI 조사 서버, Supabase 인증·PostgreSQL 저장소를 기본으로 한다. 구체 버전, 호스팅, 로그인 제공자, AI 모델은 개발 착수 시 공식 문서와 비용·접근성·연동 가능성을 확인해 선택하고 기록한다. 외부 서비스 가입·유료 결제·공개 배포는 지침 생성 승인에 포함되지 않는다.

## 완료 산출물
실행 가능한 시험 운영 앱과 서버, 설정 예시, 출처 목록, 데이터 구조, 운영 절차, 접근성·정확성 검증 기록. 자격증명은 문서나 저장소에 넣지 않는다. 실제 이용자 모집·연락은 별도 사용자 지시가 있어야 한다.

## 개발 중 확인할 사항
기관별 데이터 접근 방법·갱신 시각·수집 허용 조건, 공식 첨부 문서 형식, 운영 비용과 이용량, 시험 기기, 계정 제공자는 아직 확정하지 않았다. 확인 전 가동 가능하거나 전국 기관을 모두 지원한다고 주장하지 않는다. 미연결 출처가 있으면 시험 서비스의 실제 검색 범위를 공개한다.
