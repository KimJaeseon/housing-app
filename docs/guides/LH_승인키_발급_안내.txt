LH 공고 조회 API 승인키 발급 안내
화면 읽기 프로그램 사용자를 위한 텍스트 안내
작성 및 공식 공개 페이지 확인일: 2026년 9월 16일

1. 이 안내의 목적

우리가 만드는 앱에서 LH 공고 정보를 조회하려면 공공데이터포털의 서비스 이용 승인을 받아야 합니다.
이 안내에서 말하는 승인키는 보통 인증키 또는 서비스키라고 표시됩니다.
청약 신청을 위한 공동인증서나 금융인증서와는 다릅니다.
주택 청약을 신청하거나 당첨 자격을 심사받는 절차가 아닙니다.

준비가 끝난 상태는 다음 두 가지를 모두 만족하는 상태입니다.
첫째, 아래 LH 공고 조회 서비스의 활용신청이 승인되어 있습니다.
둘째, 일반 인증키 값을 확인할 수 있습니다.
키가 이미 있어도 이 서비스에 대한 이용 승인이 필요할 수 있습니다.

2. 읽기와 이동 방법

이 안내는 Windows의 Edge 또는 Chrome을 기준으로 설명합니다.
브라우저 주소창으로 이동하려면 컨트롤 키와 L 키를 함께 누릅니다.
주소를 붙여 넣고 엔터 키를 누르면 해당 페이지로 이동합니다.
탭 키는 다음 조작 항목으로, 시프트 키와 탭 키는 이전 항목으로 이동합니다.
링크와 버튼은 이름을 들은 뒤 엔터 키로 실행합니다.
체크 상자는 이름과 선택 상태를 확인한 뒤 스페이스 키로 선택할 수 있습니다.
화면 읽기 프로그램의 링크 목록, 버튼 목록, 제목 탐색 기능도 사용할 수 있습니다.
빠른 탐색 단축키는 센스리더, NVDA, JAWS 등 프로그램과 설정에 따라 다릅니다.

'오른쪽 위'나 '파란 버튼'처럼 화면 위치나 색으로 찾지 않아도 됩니다.
아래에 적은 항목 이름을 기준으로 찾으세요.
페이지 내용이 바뀌면 제목과 알림을 다시 읽고 다음 단계로 이동하세요.

3. 정확한 서비스 페이지 열기

다음 주소를 주소창에 입력합니다.
https://www.data.go.kr/data/15058530/openapi.do

페이지 제목이 다음 서비스인지 확인합니다.
한국토지주택공사 분양임대공고문 조회 서비스

비슷한 이름의 공급정보 서비스나 사전청약 서비스를 먼저 선택하지 않도록 합니다.
현재 만든 연결 테스트 도구는 위 공고문 조회 서비스를 사용합니다.
이 서비스의 공식 공개 페이지에는 무료와 개발단계 자동승인으로 안내되어 있습니다.
실제 승인 상태와 사용기간은 신청 후 본인 계정에서 확인해야 합니다.

4. 로그인 또는 회원가입

이미 공공데이터포털 계정이 있다면 '로그인'을 실행합니다.
계정이 없다면 '회원가입'을 실행합니다.
개인 자격으로 가입한다면 본인에게 맞는 일반회원 절차를 선택합니다.
기업이나 다른 유형에 해당하면 실제 본인 상황에 맞게 선택합니다.
가입 화면의 필수 항목과 본인확인 절차를 차례로 완료합니다.
필수 동의와 선택 동의는 각각 읽고 판단합니다.

비밀번호, 본인확인 문자번호, 인증키는 다른 사람에게 읽어 주거나 이 대화에 보내지 않습니다.
보안문자가 나타나면 '음성듣기' 등 제공되는 접근 가능한 대체 수단을 확인합니다.
조작이 되지 않으면 마지막의 문의 방법을 이용합니다.

로그인 후 다른 화면으로 이동했다면 3번의 주소를 다시 여세요.

5. 활용신청

서비스 페이지에서 '활용신청'이라는 버튼 또는 링크를 찾아 실행합니다.
로그인을 요구하면 로그인 후 다시 실행합니다.
개발계정 신청 화면이 열리면 항목 이름을 들으면서 입력합니다.
현재 계정별 신청 화면 전체를 직접 검증한 것은 아니므로 실제 항목 이름은 다를 수 있습니다.

활용 목적이나 설명을 적는 칸이 있다면 다음 문장을 참고할 수 있습니다.

서울 지역 공공 임대 및 공공분양 모집공고를 조회하는 모바일 앱의 개발과 연결 테스트에 사용합니다. 공고 출처와 확인 시점을 표시하고, 일정과 신청 조건은 공식 원문을 확인하여 제공합니다.

활용 유형은 실제 개발 용도와 맞는 항목을 선택합니다.
필수 항목을 모두 입력한 다음 이용조건을 읽고 동의 여부를 결정합니다.
신청 또는 제출을 실행합니다.
제출 후 접수 완료 안내나 오류 메시지를 확인합니다.
오류가 있으면 안내된 입력 항목으로 돌아가 수정한 뒤 다시 제출합니다.

기업회원에게 서비스키 선택 화면이 나타날 수도 있습니다.
본인이 관리하는 적절한 키를 선택하며, 선택 기준을 모르면 임의로 다른 프로젝트의 키를 고르지 마세요.

6. 승인 상태 확인

'마이페이지'에서 신청한 API 목록을 찾습니다.
찾을 때 도움이 되는 이름은 '데이터 활용', '오픈API', '활용신청 현황', '개발계정'입니다.
메뉴 구성은 바뀔 수 있으므로 이 이름들이 반드시 같은 순서로 나오는 것은 아닙니다.

신청 목록에서 '한국토지주택공사 분양임대공고문 조회 서비스'를 엽니다.
상태가 승인 또는 이용 가능한 상태인지 확인합니다.
대기나 반려라면 안내된 사유와 필요한 조치를 먼저 확인합니다.
자동승인이라는 설명만 보고 현재 본인 신청이 승인됐다고 가정하지 않습니다.

7. 일반 인증키 확인

화면에 '일반 인증키'만 있다면 그 값을 그대로 복사하세요.
인코딩과 디코딩을 따로 선택할 필요가 없습니다.
프로그램은 일반 문자열과 퍼센트로 인코딩된 형태를 모두 처리합니다.
복사 과정에서 앞뒤에 붙은 공백, 줄바꿈, 공백 HTML 표기는 정리합니다.
키 중간의 공백이나 잘못된 문자는 오류로 안내하며 임의로 지우지 않습니다.

복사 버튼이 있으면 이용하세요. 입력 상자라면 초점을 둔 뒤 컨트롤 A, 컨트롤 C로 복사합니다.
키는 문서나 채팅에 붙여 넣지 말고 다음 단계의 숨김 입력창에 넣습니다.

8. 발급받은 키로 연결 테스트

Windows PowerShell을 열고 다음 두 명령을 한 줄씩 실행합니다.
이 안내에서는 폴더 정리 후의 backend 경로를 사용합니다.

첫 번째 명령입니다.
cd C:\data\menual\housing-app-guidelines

두 번째 명령입니다.
.\.venv\Scripts\python.exe -m backend.lh_probe --posted 2026.09.01 --closing 2026.09.30 --region 11 --type 06

날짜는 테스트 예시입니다. 실제 확인하려는 공고와 공식 활용 가이드에 맞게 변경할 수 있습니다.
이 두 날짜를 단순한 게시일 시작일과 종료일로 임의 해석하지 않습니다.

'LH general service key'로 시작하는 입력 안내가 나오면 복사한 키를 붙여 넣고 엔터를 누릅니다.
키는 숨김 입력이므로 화면에 글자나 별표가 보이지 않을 수 있습니다. 입력 실패라는 뜻은 아닙니다.
터미널의 붙여넣기 단축키는 환경에 따라 컨트롤 V 또는 컨트롤 시프트 V입니다.
숨김 입력에서 값을 검토하기 어려우면 실행을 취소하고 다시 시작하세요.
환경변수에 키가 이미 설정되어 있으면 숨김 입력을 생략합니다.

9. 결과 읽기

api_success_signal: 에이피아이 성공 신호입니다. 연결 성공 신호를 받았습니다.
공고의 일정, 금액, 신청 자격까지 검증되었다는 의미는 아닙니다.

missing_key: 키가 없어서 요청하지 않았습니다.
invalid_service_key: 일반 인증키 전체를 다시 복사해 입력하세요.
unconfirmed: 연결 또는 응답을 아직 확인하지 못했습니다.
transport_error: 네트워크나 보안 연결 등 전송 문제 가능성이 있습니다.

401 또는 403이 나오면 서비스 승인 상태, 키 종류, 이용기간을 확인합니다.
429가 나오면 호출 제한을 확인하고 반복 실행을 멈춥니다.
오류 원인을 상태 번호 하나만으로 확정하지는 않습니다.

도움이 필요하면 키를 제외한 결과 요약과 어느 단계에서 막혔는지만 전달하세요.

10. 화면 읽기로 진행하기 어려울 때

공공데이터포털 대표전화: 1566-0025.
공개 페이지 안내 기준 평일 오전 9시부터 오후 6시까지이며 유료 전화입니다.
문의 예시:

화면 읽기 프로그램을 사용하고 있습니다. 한국토지주택공사 분양임대공고문 조회 서비스의 활용신청 또는 인증키 확인 단계에서 진행이 어렵습니다. 현재 초점에 읽히는 항목은 무엇이고, 실행하면 어떤 상태가 됩니다. 키 자체를 전달하지 않고 접근 가능한 방법을 안내받고 싶습니다.

본인 계정의 비밀번호나 키 전체를 불필요하게 제공하지 않습니다.

메뉴 이름이 달라지면 공개 이용가이드나 고객센터 안내를 우선 확인하세요.
