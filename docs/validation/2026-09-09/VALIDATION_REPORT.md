## 결정

1. LH 공식 목록·공급정보 API를 첫 연동 검증 후보로 삼는다. 선정은 문서·표본 구조에 근거한 개발 순서 결정이며 운영 승인 아님.
2. 각 기관의 접근 실패·미지원 범위를 사용자에게 표시하는 구조가 필수다. 실패를 0건으로 바꾸지 않는다.
3. 원문 근거가 부족한 상태에서는 확인 완료 목록에 넣지 않는다. 정정 안내가 있으면 최종본 확인 전 보류한다.
4. 자동수집 제약이 남아 있어 앱 전면 구현보다 API 실응답과 허용된 원문 확보 경로 검증이 먼저다.
