## 3. 공통 데이터 계약과 검증 표본 만들기 (1~2와 병행 가능)

- 검색 작업 / 출처 상태 / 공고 / 모집 단위 / 접수 회차 / 문서 버전 / 값별 근거를 분리한다.
- 모집 상태와 검증 상태를 별개로 둔다. 확인 실패, 값 없음, 해당 없음의 의미도 분리한다.
- 실제 표본은 최종 정정본까지 연결한 후 고정한다. 합성 경계 사례는 실제 공고와 구분한다.
- 필수 사례: 마감 시각 누락, 정정, 취소, 여러 접수 차수, 월세와 보증금 구분, 첨부 실패, 일부 출처 실패, 조건 미입력.
- 완료 기준: JSON 규격, 정상/실패 예시, 예상 판정 및 원문 위치를 담은 검증 표본.
