# P4 검증 관문 첫 단계

2026-10-08. 전체 P4 완료가 아니라 로컬 근거의 준비 상태를 판정하는 첫 단계다.

`backend.verification_gate`는 보존 PDF 해시, 검토 기록 Schema, 공고 ID, 정규화 자격 규칙과 근거 연결을 기존 검사기로 확인한다. 유효한 강서염창 자료에서는 93규칙과 미검토 차원 7개를 반환한다. 부분 검토, 외부 법령, 별도 공지, 문구 충돌 검토, 실시간 문서 연결, 운영 판정기 미구현을 각각 사유 코드로 반환한다. 외부 법령과 공지는 아직 검사하지 않았다는 뜻이며 특정 변경이 존재한다는 판정은 아니다.

```powershell
./.venv/Scripts/python.exe -m backend.verification_gate --conditions backend/eligibility_conditions/2015122300020807.json --review backend/eligibility_reviews/2015122300020807.json --pdf docs/references/lh-notice-2015122300020807.pdf
```

종료 코드 1은 유효하지만 불완전한 근거, 2는 잘못되거나 읽을 수 없는 입력이다. 현재 종료 코드 0과 verified 승격은 지원하지 않는다. 불량 입력은 공고 ID와 검증 규칙 수를 제공하지 않고 ARTIFACT_INVALID로 보류한다. 상세 원문이나 파일 경로를 오류에 출력하지 않는다. 검토 완료 불리언 입력을 받지 않는다.

## 공식 별도 공지 확인

[LH 청약접수결과 공지](https://apply.lh.or.kr/lhapply/apply/noti/an/view.do?bbsSn=9102835612&ccrCnntSysDsCd=03&mi=1079)를 2026-10-08 웹 조회했다. 제목은 강서염창 통합공공임대주택 청약접수결과, 게시일은 2026-10-01이다. 본문은 접수결과 및 경쟁률 게시 안내이며 첨부 이름은 2026-09-17 공고를 명시한다. 첨부 내용·해시는 이번 단계에서 검토하지 않았다. 공고 번호 직접 연결을 확인하지 않았으므로 기존 모집공고의 자격·금액을 갱신하지 않는다. 별도 변경 공지 전체 조사 완료나 변경 없음의 증거로 사용하지 않는다.

## 범위와 후속

검증: 서버 전체 198개 통과 후 CLI 종료 코드·JSON 출력 검사 1개를 추가해 전용 6개를 재검사했다. 참조 규칙 26개 통과. 독립 읽기 검토에서 결함 없음. 기존 Starlette 테스트 클라이언트 deprecation 경고는 비차단이다.

- 앱/API 응답 계약과 화면은 변경하지 않았다. 운영 verified 차단은 유지한다.
- 다음은 별도 공지 원문·첨부·공고 관계를 보존하는 계약과 어댑터, 적용 시점별 법령 확인, 문구 충돌의 공식 근거 확보다.
- 모든 필수 항목을 충족한 긍정 경로와 누락·충돌 부정 경로를 구현한 뒤 API 판정 사유를 연결한다.
- 실제 아이폰·안드로이드 테스트는 사용자 요청에 따라 제외했다.
