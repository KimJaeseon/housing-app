# 공고문 검토 기록 연결 검증 — 2026-10-01

대상: 기존 서울번동3 정정공고 17개 항목의 새 기록 형식 이관, 런타임 검사, 검토일 표시. 공식 PDF는 기존 로컬 표본을 사용했다. 이번 작업에서 실제 LH API 또는 웹사이트를 다시 호출하지 않았다.

## 구현과 판정

- `document-review.schema.json`과 `backend/document_review.py`가 검토 기록의 구조, 공고 식별자, 중복 사실 ID, 쪽 범위, 위치 표시, PDF SHA-256을 확인한다.
- 기존 기록을 새 구조로 이관했다. `lh_document.py`는 기록이 유효하고 새로 받은 PDF·정정 관계가 일치할 때만 17개 항목을 반환한다. 형식 오류나 파일 변경 때는 확인값을 보류한다.
- API에 `reviewed_at`을 추가했다. 화면은 이를 `checked_at` 원문 조회 시각과 별도로 읽을 수 있는 텍스트로 표시한다. 미검토 범위도 경고 문장으로 제공한다.
- `verified` 공고 생성은 여전히 차단한다. 기록 형식 검사는 사실 내용의 정확성이나 공고 전체 자격을 증명하지 않는다.
