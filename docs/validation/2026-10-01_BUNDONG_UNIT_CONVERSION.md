[구조화 기록](../../backend/structured_conditions/2015122300020605.json)은 각 행을 기존 [검토 사실](../../backend/document_reviews/2015122300020605.json)의 ID에 연결한다. 검토 사실의 전환 2건에는 기본 보증금 대비 증감액과 원문 단위를 명시했다. [검사 도구](../../backend/structured_conditions.py)는 원문 수치의 1,000배 환산, 전환액 합계, 월세 변화 방향, 대상·주택형·조건과 PDF 해시를 확인한다. 강서염창의 원 단위 표본도 같은 검사로 계속 통과한다.

기존 17개 검토 항목 이외의 자격·임대조건은 추가하지 않았다. 구조화 기록은 내부 검토 자료로 남으며 앱의 신청 가능·개인 자격·`verified` 판정에는 연결하지 않는다. VoiceOver·TalkBack 실기 검사는 사용자 요청대로 후순위다.

서버 전체 회귀검사 162개와 참조 규칙 26개가 통과했다. PDF 해시 검사 CLI는 기존 17항목을, 구조화 조건 CLI는 서울번동3 임대조건 7개와 강서염창 접수 2회차·임대조건 6개를 확인했다.
