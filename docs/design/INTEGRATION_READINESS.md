# 실제 연동 준비

2026-09-10. 가입·활용신청·기관 연락은 실행하지 않음.

## LH 우선 확인

공식 목록 API: https://www.data.go.kr/data/15058530/openapi.do
공급정보 API: https://www.data.go.kr/data/15056765/openapi.do

서버 설정 이름 제안: LH_SERVICE_KEY. 승인키는 서버 환경변수에만 둔다. 예시 문서에는 값이나 실제 요청 URL을 기록하지 않는다. URL 쿼리에 키가 포함되는 경우 HTTP 클라이언트·프록시 로그에서 제거한다.

키 설정 후 실행할 검증:
1. 승인된 서비스의 공식 가이드 최신 버전을 확인한다.
2. 수도권 표본 목록 1페이지 요청, 원문 URL과 실제 유형 비교.
3. 전체 페이지 처리와 중복/누락 확인.
4. 빈 결과와 인증 오류, 요청 제한, timeout을 각각 구별.
5. 공급정보와 모집 단위별 금액·접수 회차를 원문과 대조.
6. 정정·취소 처리와 원문 접근 조건을 확인한 출처만 활성화.

## 기관 문의 초안 (미발송)

수도권 공공주택 모집공고를 이용자가 검색할 때마다 확인하여 제공하는 모바일 앱을 준비하고 있습니다. 공개 API의 목록·상세·첨부 접근 경로, 호출 제한 및 갱신 주기를 확인하고자 합니다. 첨부에서 모집 일정·금액·자격을 구조화하고 출처와 확인시점을 표시하는 사용 방식의 허용 범위, 정정·취소 공고를 연결할 식별정보가 있는지 안내 부탁드립니다.

LH에는 첨부 경로 제한과 허용된 대체 경로, SH·GH에는 허용된 자동 조회 API, iH에는 이용조건상 구조화·요약 가능 범위를 각각 추가 확인한다. 실제 연락은 사용자 지시 후 수행한다.

현재 API 성공 응답은 없으며 실연동 준비 완료로 표시하지 않는다.
