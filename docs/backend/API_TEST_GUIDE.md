외부 의존성 없이 Python 표준 라이브러리만 사용합니다. 항상 PAGE=1, PG_SZ=3으로 한 번만 요청하고 자동 재시도·리다이렉트는 하지 않습니다. 연결 대기시간은 15초이며 응답 읽기는 최대 1 MiB로 제한합니다. 요청 URL·키·원응답·예외문을 출력하거나 파일로 보관하지 않습니다.

## 3. 출력 해석

- `api_success_signal`: HTTP 200과 JSON의 `SS_CODE=Y`를 관찰했습니다. **JSON 전체 구조 및 공고 검증 완료는 아닙니다.** 종료 코드는 0입니다.
- `json_shape=list_envelope_validated`: 관찰한 목록 응답 구조·식별자·건수 일관성 검사를 통과했습니다. `notice_verification=pending`은 공고 원문 검증이 남았음을 의미합니다. `candidate_row_count`가 표시되어도 참고용입니다. 0건으로 전체 공고가 없다고 판단하지 않습니다.
- `not_called / missing_key`: 키가 없으므로 외부 요청하지 않았습니다.
- `not_called / invalid_service_key`: 일반 인증키인지 확인합니다.
- `unconfirmed` + HTTP 401/403: 승인 상태·키 종류·이용기간을 확인합니다. 상태만으로 원인을 확정하지 않습니다.
- HTTP 429: 호출 제한을 확인하고 반복 호출을 멈춥니다.
- `http_error_or_redirect`: 해당 상태코드를 참고하고 공식 주소·접근 조건을 재확인합니다.
- `unrecognized_response` / `json_response_not_verified`: XML 오류나 예상과 다른 JSON일 수 있습니다. 빈 결과로 처리하지 않습니다.
- `transport_error`: 네트워크·TLS·timeout 등 전송 문제 가능성이 있습니다. 원인별 분류는 미구현입니다.

0 이외의 종료 코드는 2입니다. 질문할 때는 도구의 안전한 요약 출력과 키 없는 실행 옵션만 공유하세요.
